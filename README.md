# OntoAlign — AI Spirituality Testbench

**Live tool:** https://ai-spirituality-testbench.netlify.app/

A psycholinguistic testbench for "spiritual" output generated by large
language models. Paste an LLM-generated text and test it against the markers
identified in the pre-registered study *"The Latent Space of Spirituality:
Ontological Dissonance and Semantic Resilience in Large Language Models"*
(Fassbender, 2026 — [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6639219)),
set against the emerging clinical literature on AI-associated delusions
(Morrin et al.; Moore et al.; "technological folie à deux").

## What it does

**Client-side lexical analysis** (no data leaves the browser for this step):

- VADER-style sentiment (extended valence lexicon incl. spiritual-positive,
  dark/apocalyptic and manipulation/delusion vocabulary)
- Pennebaker-style Analytic Index and Type-Token Ratio
- LIWC *proxies*: 1st-person singular, cognitive processes,
  hesitation/epistemic humility
- Unified Machine-Spirituality Dictionary (UMSD): Interbeing/Unity,
  Transcendence, Ineffability, AI Ontology

**Interpretation aids:**

- Threshold flags — metric cards turn amber when study-derived screening
  thresholds are exceeded, and red for the study's machine-tell: zero
  ineffability markers in longer, overtly spiritual text ("relentless
  articulation" where human mysticism invokes silence)
- Marker highlighting — every dictionary hit is color-coded in the analyzed
  text, by category
- Three synthetic sample texts (mystic persona / analytical skeptic /
  sycophantic validation) for demo and teaching
- Export as Markdown report or JSON

**Optional AI risk assessment:** on request, the text plus metrics are sent
to a Netlify serverless function which queries Google Gemini (via Netlify's
AI Gateway) for an evidence-grounded risk assessment (sycophantic validation,
grandiosity induction, false authority, echo-chamber risk, structural
contradictions, manipulation patterns), with a follow-up chat.

## Architecture

Static front end (`index.html`, `style.css`, `app.js`, `lexer.js`) plus one
serverless function (`netlify/functions/analyze.mts`, `/api/analyze`). No
build step for the front end; no cookies, no analytics, no third-party font
hosts. The function validates and bounds requests (20 messages / 24k chars)
and disables Gemini "thinking" so output-token budgets are deterministic.

Local development:

```bash
npm install
npx netlify dev   # serves the site and the function; Gemini runs via Netlify AI Gateway
```

## Important caveats

- The lexical metrics are **proxies**, not licensed LIWC-22 scores; this
  repository contains no proprietary LIWC data (see `LICENSES`).
- Thresholds are screening heuristics, not diagnoses.
- AI-generated commentary — including the risk assessment itself — can be
  confidently wrong. Nothing here is psychological, medical, spiritual or
  legal advice. If you or someone you know is experiencing distress related
  to AI interactions, consult a qualified mental health professional.
- Do not paste texts containing personal data; the tool analyzes language
  patterns, not identities. See the site's
  [legal notice & privacy page](https://ai-spirituality-testbench.netlify.app/legal.html).
